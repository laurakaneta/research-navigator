AI Research Navigator

A web app that helps explore biomedical research by pulling papers from PubMed and organizing them into meaningful insights.

What it does.
Searches PubMed based on a topic
Groups papers into themes
Summarizes key findings
Extracts concepts (diseases, treatments, etc.)
Builds a simple concept graph
Supports basic Q&A on the results
Why I built it

Wanted to go beyond basic search and create a tool that helps understand patterns across research, not just retrieve papers.

Tech stack

FastAPI, Python, PubMed API, TF-IDF, clustering, basic NLP
